**Curated List of SaaS Products & Open-Source GitHub Projects**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Automated Test Frameworks**. These tools help engineering teams create, run, and maintain automated tests for web, mobile, API, and desktop applications.



**Examples** include ServiceNow Automated Test Framework, Katalon, Tricentis Tosca, Selenium, Cypress Cloud, Playwright, mabl, Testim, BrowserStack, and Sauce Labs (the category leaders).

## SaaS/Hosted Platforms

- **[ServiceNow Automated Test Framework (ATF)](https://www.servicenow.com/)**  

  Built-in test automation framework within the ServiceNow platform for testing applications and workflows on the ServiceNow platform.



- **[Katalon](https://katalon.com/)**  

  Low-code and full-code test automation platform supporting web, API, mobile, and desktop testing with AI-assisted features.



- **[Tricentis Tosca](https://www.tricentis.com/products/automate-continuous-testing-tosca)**  

  Enterprise model-based test automation platform focused on end-to-end testing, risk-based testing, and continuous testing at scale.



- **[Cypress Cloud](https://www.cypress.io/cloud)**  

  Commercial cloud companion to the open-source Cypress framework, offering test parallelization, recording, analytics, and collaboration features.



- **[mabl](https://www.mabl.com/)**  

  Intelligent test automation platform that uses machine learning for auto-healing tests, coverage insights, and low-maintenance end-to-end testing.



- **[Testim](https://www.testim.io/)**  

  AI-powered test automation platform focused on creating stable, maintainable end-to-end tests with smart locators and self-healing capabilities.



- **[BrowserStack](https://www.browserstack.com/)**  

  Leading cloud testing platform providing access to real browsers and devices for automated and manual testing across web and mobile.



- **[Sauce Labs](https://saucelabs.com/)**  

  Cloud-based continuous testing platform offering automated testing on real devices and browsers with extensive analytics and CI/CD integrations.



- **[LambdaTest](https://www.lambdatest.com/)**  

  Cloud-based cross-browser and mobile testing platform supporting Selenium, Playwright, Cypress, and other frameworks at scale.



- **[Perfecto](https://www.perfecto.io/)**  

  Enterprise mobile and web testing platform focused on continuous testing and real-device cloud execution.



## Open-Source GitHub Projects

- **[Selenium](https://github.com/SeleniumHQ/selenium)**  

  The original and still foundational open-source browser automation framework. Supports multiple languages and remains the backbone of many testing tools and grids.



- **[Playwright](https://github.com/microsoft/playwright)**  

  Modern open-source end-to-end testing framework by Microsoft. Excellent cross-browser support (Chromium, Firefox, WebKit), auto-waiting, powerful tracing, and multi-language bindings.



- **[Cypress](https://github.com/cypress-io/cypress)**  

  Popular open-source JavaScript end-to-end testing framework known for its developer-friendly experience, time-travel debugging, and real-browser execution.



- **[Appium](https://github.com/appium/appium)**  

  Leading open-source framework for automating native, hybrid, and mobile web applications on iOS, Android, and other platforms.



- **[Robot Framework](https://github.com/robotframework/robotframework)**  

  Generic open-source automation framework that uses keyword-driven testing. Excellent for acceptance testing and highly readable test cases.



- **[WebdriverIO](https://github.com/webdriverio/webdriverio)**  

  Next-gen browser and mobile automation test framework for Node.js. Highly extensible and supports both WebDriver and DevTools protocols.



- **[TestCafe](https://github.com/DevExpress/testcafe)**  

  Open-source Node.js end-to-end testing framework that does not require WebDriver, offering a simple API and built-in waiting mechanisms.



- **[SeleniumBase](https://github.com/seleniumbase/SeleniumBase)**  

  Powerful open-source framework built on Selenium that adds simplified APIs, test runners, dashboards, and advanced automation utilities.



- **[CodeceptJS](https://github.com/codeceptjs/CodeceptJS)**  

  Modern end-to-end testing framework with a high-level scenario-driven syntax that can run on top of Playwright, WebDriver, or Puppeteer.



- **[Karate](https://github.com/karatelabs/karate)**  

  Open-source unified test automation framework for API testing, UI automation, and performance testing using a simple, readable syntax.



### Additional Strong Open-Source Options

- Browser automation: **Selenium**, **Playwright**, **Cypress**, **WebdriverIO**, **TestCafe**.

- Mobile automation: **Appium**.

- Keyword / acceptance testing: **Robot Framework**.

- API + UI: **Karate**, **CodeceptJS**.

- Supporting tools: Selenium Grid, Playwright Trace Viewer, Allure Report, pytest, JUnit, TestNG.

- Accepting that commercial platforms (Katalon, Tricentis Tosca, mabl, Testim, BrowserStack, Sauce Labs) still lead in low-code experiences, AI auto-healing, enterprise reporting, device clouds, and managed infrastructure.



**Frameworks for building custom systems**:  

Choose a core engine (**Playwright**, **Selenium**, or **Cypress**) → structure tests with **Robot Framework** or page-object patterns → run on open grids or self-hosted browsers → add reporting with Allure or built-in tools → scale with CI/CD. Ideal for teams that want full control, no vendor lock-in, and the ability to customize every layer of the testing stack.
